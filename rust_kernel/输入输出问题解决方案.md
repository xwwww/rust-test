# 输入输出问题解决方案

## 问题分析 🔍

您遇到的"无法输入输出"是**完全正常**的现象！原因如下：

### 1. **当前内核状态**
- 内核成功启动了 ✅
- 但还没有实现 VGA 文本输出 ❌
- 也没有实现键盘输入处理 ❌
- 程序进入了无限循环 `loop {}`

### 2. **为什么看不到输出？**
```rust
#[no_mangle]
pub extern "C" fn _start() -> ! {
    // 这里还没有实现任何输出功能
    loop {}  // 程序在这里无限循环
}
```

## 立即解决方案 🛠️

### 方案一：添加基本的 VGA 输出

修改 `src/main.rs`：

```rust
#![no_std]
#![no_main]

use core::panic::PanicInfo;

// VGA 文本缓冲区地址
const VGA_BUFFER: *mut u8 = 0xb8000 as *mut u8;

#[no_mangle]
pub extern "C" fn _start() -> ! {
    // 清屏并显示欢迎信息
    clear_screen();
    print_string(b"Hello from Rust OS!", 0, 0);
    print_string(b"System started successfully!", 1, 0);
    
    loop {}
}

// 清屏函数
fn clear_screen() {
    unsafe {
        for i in 0..(80 * 25 * 2) {
            *VGA_BUFFER.add(i) = 0;
        }
    }
}

// 打印字符串函数
fn print_string(string: &[u8], row: usize, col: usize) {
    unsafe {
        let mut offset = (row * 80 + col) * 2;
        for &byte in string {
            *VGA_BUFFER.add(offset) = byte;      // 字符
            *VGA_BUFFER.add(offset + 1) = 0x0f;  // 白色文字，黑色背景
            offset += 2;
        }
    }
}

#[panic_handler]
fn panic(info: &PanicInfo) -> ! {
    // 显示 panic 信息
    print_string(b"KERNEL PANIC!", 10, 0);
    if let Some(location) = info.location() {
        print_string(b"Check the code!", 11, 0);
    }
    loop {}
}
```

### 方案三：创建完整的 VGA 驱动

创建 `src/vga_buffer.rs`：

```rust
use volatile::Volatile;
use core::fmt;

#[allow(dead_code)]
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(u8)]
pub enum Color {
    Black = 0,
    Blue = 1,
    Green = 2,
    Cyan = 3,
    Red = 4,
    Magenta = 5,
    Brown = 6,
    LightGray = 7,
    DarkGray = 8,
    LightBlue = 9,
    LightGreen = 10,
    LightCyan = 11,
    LightRed = 12,
    Pink = 13,
    Yellow = 14,
    White = 15,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(transparent)]
struct ColorCode(u8);

impl ColorCode {
    fn new(foreground: Color, background: Color) -> ColorCode {
        ColorCode((background as u8) << 4 | (foreground as u8))
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(C)]
struct ScreenChar {
    ascii_character: u8,
    color_code: ColorCode,
}

const BUFFER_HEIGHT: usize = 25;
const BUFFER_WIDTH: usize = 80;

#[repr(transparent)]
struct Buffer {
    chars: [[Volatile<ScreenChar>; BUFFER_WIDTH]; BUFFER_HEIGHT],
}

pub struct Writer {
    column_position: usize,
    color_code: ColorCode,
    buffer: &'static mut Buffer,
}

impl Writer {
    pub fn write_byte(&mut self, byte: u8) {
        match byte {
            b'\n' => self.new_line(),
            byte => {
                if self.column_position >= BUFFER_WIDTH {
                    self.new_line();
                }

                let row = BUFFER_HEIGHT - 1;
                let col = self.column_position;

                let color_code = self.color_code;
                self.buffer.chars[row][col].write(ScreenChar {
                    ascii_character: byte,
                    color_code,
                });
                self.column_position += 1;
            }
        }
    }

    pub fn write_string(&mut self, s: &str) {
        for byte in s.bytes() {
            match byte {
                0x20..=0x7e | b'\n' => self.write_byte(byte),
                _ => self.write_byte(0xfe),
            }
        }
    }

    fn new_line(&mut self) {
        for row in 1..BUFFER_HEIGHT {
            for col in 0..BUFFER_WIDTH {
                let character = self.buffer.chars[row][col].read();
                self.buffer.chars[row - 1][col].write(character);
            }
        }
        self.clear_row(BUFFER_HEIGHT - 1);
        self.column_position = 0;
    }

    fn clear_row(&mut self, row: usize) {
        let blank = ScreenChar {
            ascii_character: b' ',
            color_code: self.color_code,
        };
        for col in 0..BUFFER_WIDTH {
            self.buffer.chars[row][col].write(blank);
        }
    }
}

impl fmt::Write for Writer {
    fn write_str(&mut self, s: &str) -> fmt::Result {
        self.write_string(s);
        Ok(())
    }
}

// 全局 Writer 实例
use lazy_static::lazy_static;
use spin::Mutex;

lazy_static! {
    pub static ref WRITER: Mutex<Writer> = Mutex::new(Writer {
        column_position: 0,
        color_code: ColorCode::new(Color::Yellow, Color::Black),
        buffer: unsafe { &mut *(0xb8000 as *mut Buffer) },
    });
}

// 宏定义
#[macro_export]
macro_rules! print {
    ($($arg:tt)*) => ($crate::vga_buffer::_print(format_args!($($arg)*)));
}

#[macro_export]
macro_rules! println {
    () => ($crate::print!("\n"));
    ($($arg:tt)*) => ($crate::print!("{}\n", format_args!($($arg)*)));
}

#[doc(hidden)]
pub fn _print(args: fmt::Arguments) {
    use core::fmt::Write;
    WRITER.lock().write_fmt(args).unwrap();
}

// 测试函数
pub fn print_something() {
    use core::fmt::Write;
    let mut writer = Writer {
        column_position: 0,
        color_code: ColorCode::new(Color::Yellow, Color::Black),
        buffer: unsafe { &mut *(0xb8000 as *mut Buffer) },
    };

    writer.write_byte(b'H');
    writer.write_string("ello ");
    writer.write_string("Wörld!");
    writeln!(writer, "The numbers are {} and {}", 42, 1.337).unwrap();
}
```

## 关于键盘输入 ⌨️

**为什么现在还不能输入？**

键盘输入需要：
1. **中断处理系统** - 处理键盘中断
2. **键盘驱动程序** - 解析扫描码
3. **输入缓冲区** - 存储按键数据

这些将在第二周学习！现在专注于输出功能。

## 调试技巧 🔧

### 1. 使用串口输出调试
```rust
// 添加串口输出用于调试
use uart_16550::SerialPort;

static mut SERIAL1: SerialPort = unsafe { SerialPort::new(0x3F8) };

fn serial_println(s: &str) {
    unsafe {
        for byte in s.bytes() {
            SERIAL1.send(byte);
        }
        SERIAL1.send(b'\n');
    }
}

#[no_mangle]
pub extern "C" fn _start() -> ! {
    serial_println("Kernel started!");  // 这会在终端显示
    
    // VGA 输出
    println!("Hello from VGA!");
    
    loop {}
}
```

## 快速测试方案 🚀

如果您想立即看到效果，使用这个最简单的版本：

```rust
#![no_std]
#![no_main]

use core::panic::PanicInfo;

#[no_mangle]
pub extern "C" fn _start() -> ! {
    let vga_buffer = 0xb8000 as *mut u8;
    
    unsafe {
        // 清屏
        for i in 0..(80 * 25 * 2) {
            *vga_buffer.add(i) = 0;
        }
        
        // 显示 "RUST OS"
        let message = b"RUST OS STARTED!";
        for (i, &byte) in message.iter().enumerate() {
            *vga_buffer.add(i * 2) = byte;      // 字符
            *vga_buffer.add(i * 2 + 1) = 0x0f;  // 颜色（白色）
        }
    }
    
    loop {}
}

#[panic_handler]
fn panic(_info: &PanicInfo) -> ! {
    loop {}
}
```

现在重新编译运行，您应该能看到 "RUST OS STARTED!" 的输出了！
