## 第一部分：VGA 硬件光标控制 (20分钟)

### 1. 理解 VGA 光标机制

VGA 文本模式中的光标是由硬件控制的，通过特定的端口寄存器来设置位置：

```rust
// VGA 光标控制端口
const VGA_CURSOR_COMMAND_PORT: u16 = 0x3D4;
const VGA_CURSOR_DATA_PORT: u16 = 0x3D5;

// 光标位置寄存器
const CURSOR_LOCATION_HIGH: u8 = 0x0E;
const CURSOR_LOCATION_LOW: u8 = 0x0F;
```

### 2. 光标位置计算

```rust
// 将 (x, y) 坐标转换为线性位置
fn position_to_offset(x: usize, y: usize) -> u16 {
    (y * SCREEN_WIDTH + x) as u16
}

// 将线性位置转换为 (x, y) 坐标
fn offset_to_position(offset: u16) -> (usize, usize) {
    let offset = offset as usize;
    (offset % SCREEN_WIDTH, offset / SCREEN_WIDTH)
}
```

### 3. 端口 I/O 操作

```rust
use core::arch::asm;

// 向端口写入字节
unsafe fn outb(port: u16, value: u8) {
    asm!(
        "out dx, al",
        in("dx") port,
        in("al") value,
        options(nomem, nostack, preserves_flags)
    );
}

// 从端口读取字节
unsafe fn inb(port: u16) -> u8 {
    let value: u8;
    asm!(
        "in al, dx",
        out("al") value,
        in("dx") port,
        options(nomem, nostack, preserves_flags)
    );
    value
}
```

            color_code: ColorCode::new(Color::White, Color::Black),

        writer.update_hardware_cursor();
        writer
    }

### 2. 实现光标控制方法

```rust
impl VgaWriter {
    // 更新硬件光标位置
    fn update_hardware_cursor(&self) {
        if !self.cursor_enabled {
            return;
        }
        
        let position = position_to_offset(self.column_position, self.row_position);
        
        unsafe {
            // 设置光标位置的高字节
            outb(VGA_CURSOR_COMMAND_PORT, CURSOR_LOCATION_HIGH);
            outb(VGA_CURSOR_DATA_PORT, (position >> 8) as u8);
            
            // 设置光标位置的低字节
            outb(VGA_CURSOR_COMMAND_PORT, CURSOR_LOCATION_LOW);
            outb(VGA_CURSOR_DATA_PORT, position as u8);
        }
    }
    
    // 设置光标位置
    pub fn set_cursor_position(&mut self, x: usize, y: usize) {
        if x < SCREEN_WIDTH && y < SCREEN_HEIGHT {
            self.column_position = x;
            self.row_position = y;
            self.update_hardware_cursor();
        }
    }
    
    // 获取当前光标位置
    pub fn get_cursor_position(&self) -> (usize, usize) {
        (self.column_position, self.row_position)
    }
    
    // 启用/禁用光标
    pub fn set_cursor_enabled(&mut self, enabled: bool) {
        self.cursor_enabled = enabled;
        if enabled {
            self.update_hardware_cursor();
        } else {
            // 将光标移到屏幕外隐藏
            unsafe {
                outb(VGA_CURSOR_COMMAND_PORT, CURSOR_LOCATION_HIGH);
                outb(VGA_CURSOR_DATA_PORT, 0xFF);
                outb(VGA_CURSOR_COMMAND_PORT, CURSOR_LOCATION_LOW);
                outb(VGA_CURSOR_DATA_PORT, 0xFF);
            }
        }
    }
    
    // 移动光标（相对移动）
    pub fn move_cursor(&mut self, dx: isize, dy: isize) {
        let new_x = (self.column_position as isize + dx).max(0).min(SCREEN_WIDTH as isize - 1) as usize;
        let new_y = (self.row_position as isize + dy).max(0).min(SCREEN_HEIGHT as isize - 1) as usize;
        self.set_cursor_position(new_x, new_y);
    }
}
```

## 第三部分：高级格式化输出 (10分钟)

### 1. 扩展字符写入功能

```rust
impl VgaWriter {
    // 改进的字符写入方法
    pub fn write_char(&mut self, c: u8) {
        match c {
            b'\n' => self.new_line(),
            b'\r' => {
                self.column_position = 0;
                self.update_hardware_cursor();
            },
            b'\t' => {
                // 制表符支持（4个空格对齐）
                let spaces = 4 - (self.column_position % 4);
                for _ in 0..spaces {
                    self.write_char(b' ');
                }
            },
            b'\x08' => {
                // 退格键支持
                if self.column_position > 0 {
                    self.column_position -= 1;
                    self.write_char_at(b' ', self.column_position, self.row_position);
                    self.update_hardware_cursor();
                }
            },
            c => {
                if self.column_position >= SCREEN_WIDTH {
                    self.new_line();
                }
                
                self.write_char_at(c, self.column_position, self.row_position);
                self.column_position += 1;
                self.update_hardware_cursor();
            }
        }
    }
    
    // 在指定位置写入字符
    fn write_char_at(&mut self, c: u8, x: usize, y: usize) {
        if x < SCREEN_WIDTH && y < SCREEN_HEIGHT {
            self.buffer.chars[y][x] = ScreenChar {
                ascii_character: c,
                color_code: self.color_code,
            };
        }
    }
    
    // 改进的换行方法
    fn new_line(&mut self) {
        if self.row_position >= SCREEN_HEIGHT - 1 {
            // 滚动屏幕
            self.scroll_up();
        } else {
            self.row_position += 1;
        }
        self.column_position = 0;
        self.update_hardware_cursor();
    }
    
    // 屏幕向上滚动
    fn scroll_up(&mut self) {
        for row in 1..SCREEN_HEIGHT {
            for col in 0..SCREEN_WIDTH {
                let character = self.buffer.chars[row][col];
                self.buffer.chars[row - 1][col] = character;
            }
        }
        self.clear_row(SCREEN_HEIGHT - 1);
    }
}
```

### 1. 创建彩色打印宏

```rust
// 彩色打印宏
#[macro_export]
macro_rules! print_colored {
    ($fg:expr, $bg:expr, $($arg:tt)*) => {{
        use core::fmt::Write;
        let mut writer = $crate::vga_buffer::WRITER.lock();
        let old_color = writer.color_code;
        writer.set_color($fg, $bg);
        let _ = write!(writer, $($arg)*);
        writer.color_code = old_color;
    }};
}

#[macro_export]
macro_rules! println_colored {
    ($fg:expr, $bg:expr) => {
        $crate::print_colored!($fg, $bg, "\n")
    };
    ($fg:expr, $bg:expr, $($arg:tt)*) => {{
        $crate::print_colored!($fg, $bg, $($arg)*);
        $crate::print_colored!($fg, $bg, "\n");
    }};
}
```

### 2. 创建定位打印宏

```rust
// 在指定位置打印
#[macro_export]
macro_rules! print_at {
    ($x:expr, $y:expr, $($arg:tt)*) => {{
        use core::fmt::Write;
        let mut writer = $crate::vga_buffer::WRITER.lock();
        let old_pos = writer.get_cursor_position();
        writer.set_cursor_position($x, $y);
        let _ = write!(writer, $($arg)*);
        writer.set_cursor_position(old_pos.0, old_pos.1);
    }};
}

// 在指定位置打印彩色文本
#[macro_export]
macro_rules! print_at_colored {
    ($x:expr, $y:expr, $fg:expr, $bg:expr, $($arg:tt)*) => {{
        use core::fmt::Write;
        let mut writer = $crate::vga_buffer::WRITER.lock();
        let old_pos = writer.get_cursor_position();
        let old_color = writer.color_code;
        writer.set_cursor_position($x, $y);
        writer.set_color($fg, $bg);
        let _ = write!(writer, $($arg)*);
        writer.color_code = old_color;
        writer.set_cursor_position(old_pos.0, old_pos.1);
    }};
}
```

## 常见问题解答 ❓

**Q: 为什么需要硬件光标同步？**
A: 软件维护的光标位置和硬件显示的光标可能不一致，同步确保用户看到的光标位置正确。

**Q: 端口 I/O 操作为什么要用 unsafe？**
A: 端口操作直接与硬件交互，可能影响系统稳定性，Rust 要求显式标记为 unsafe。

**Q: 宏和函数有什么区别？**
A: 宏在编译时展开，可以生成任意代码；函数在运行时调用，有固定的参数和返回类型。

**Q: 如何调试宏展开？**
A: 使用 `cargo expand` 命令可以查看宏展开后的代码。
