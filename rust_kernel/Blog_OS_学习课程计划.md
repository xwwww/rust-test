# Blog OS 项目 - Rust 操作系统开发学习课程

## 课程概述

本课程基于 Philipp Oppermann 的 Blog OS 项目，设计为 12 周的系统性学习计划，每天约 1 小时的学习时间。课程将带您从零开始，使用 Rust 语言构建一个功能完整的小型操作系统内核。

**课程目标：**
- 掌握 Rust 系统编程技能
- 理解操作系统核心概念
- 学会底层硬件交互
- 建立完整的 OS 开发知识体系

**学习方式：**
- 理论学习 + 实践编程
- 每日 1 小时，周末可适当延长
- 循序渐进，每周一个主题模块

## 第一周：环境搭建与 Rust 基础

### 第1天：开发环境准备 (1小时)
**学习内容：**
- 安装 Rust 工具链
- 配置 QEMU 虚拟机
- 设置 VS Code 或其他 IDE
- 克隆 Blog OS 项目

**实践任务：**
```bash
# 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 安装必要组件
rustup component add rust-src
rustup component add llvm-tools-preview
cargo install bootimage

# 安装 QEMU
# Ubuntu/Debian: sudo apt install qemu-system-x86
# macOS: brew install qemu
# Windows: 下载 QEMU 安装包

# 克隆项目
git clone https://github.com/phil-opp/blog_os.git
cd blog_os
```

**验证环境：**
- 成功编译并运行 Hello World 内核
- QEMU 能正常启动虚拟机

## 学习建议

### 每日学习流程
1. **理论学习** (20分钟): 阅读相关文档和教程
2. **代码实践** (30分钟): 编写和调试代码
3. **总结反思** (10分钟): 记录学习笔记和问题

### 学习技巧
- **循序渐进**: 不要跳跃式学习，确保每个概念都理解透彻
- **动手实践**: 理论结合实践，多写代码多调试
- **记录笔记**: 记录重要概念和遇到的问题
- **社区交流**: 积极参与社区讨论，寻求帮助

### 常见问题解决
- **编译错误**: 检查 Rust 版本和依赖配置
- **运行时错误**: 使用调试工具定位问题
- **概念理解**: 查阅官方文档和参考资料
- **环境问题**: 参考官方安装指南

- 学习更多系统编程语言 (C, Assembly)

### 操作系统方向
- 研究现代操作系统设计

- 深入学习 Rust 高级特性
