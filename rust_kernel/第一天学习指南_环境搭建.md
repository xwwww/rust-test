# 第一天学习指南：开发环境准备

## 学习目标 🎯
- 搭建完整的 Rust 操作系统开发环境
- 成功编译并运行第一个内核程序
- 理解基本的工具链和开发流程

## 时间分配 ⏰
- **环境安装** (30分钟)
- **项目设置** (20分钟) 
- **验证测试** (10分钟)

---

## 第一部分：安装 Rust 工具链 (15分钟)

### 1. 安装 Rust
```bash
# 下载并安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 重新加载环境变量
source ~/.cargo/env

# 验证安装
rustc --version
cargo --version
```

**预期输出示例：**
```
rustc 1.75.0 (82e1608df 2023-12-21)
cargo 1.75.0 (1d8b05cdd 2023-12-20)
```

### 2. 安装必要组件
```bash
# 安装 Rust 源码（用于 no_std 开发）
rustup component add rust-src

# 安装 LLVM 工具（用于链接和调试）
rustup component add llvm-tools-preview

# 安装 bootimage 工具（用于创建可启动镜像）
cargo install bootimage
```

### 3. 添加目标平台
```bash
# 添加裸机目标平台
rustup target add thumbv7em-none-eabihf
```

---

## 第二部分：安装 QEMU 虚拟机 (10分钟)

### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install qemu-system-x86
```

### macOS
```bash
# 使用 Homebrew
brew install qemu
```

### Windows
1. 下载 QEMU 安装包：https://www.qemu.org/download/#windows
2. 运行安装程序，使用默认设置
3. 将 QEMU 添加到系统 PATH

### 验证 QEMU 安装
```bash
qemu-system-x86_64 --version
```

---

## 第三部分：克隆和设置项目 (15分钟)

### 1. 克隆 Blog OS 项目
```bash
# 克隆官方仓库
git clone https://github.com/phil-opp/blog_os.git
cd blog_os

# 查看项目结构
ls -la
```

### 2. 检查项目文件
```bash
# 查看主要配置文件
cat Cargo.toml
cat .cargo/config.toml
cat x86_64-blog_os.json
```

### 3. 理解项目结构
```
blog_os/
├── Cargo.toml              # 项目依赖和配置
├── src/
│   ├── main.rs             # 内核入口点
│   └── lib.rs              # 库代码
├── tests/                  # 集成测试
├── .cargo/
│   └── config.toml         # Cargo 配置
└── x86_64-blog_os.json     # 自定义目标规范
```

---

## 第四部分：编译和运行 (10分钟)

### 1. 编译内核
```bash
# 编译项目
cargo build

# 如果遇到错误，尝试：
cargo build --target x86_64-blog_os.json
```

### 2. 创建启动镜像
```bash
# 创建可启动的磁盘镜像
cargo bootimage
```

### 3. 运行内核
```bash
# 在 QEMU 中运行
cargo run

# 或者手动运行
qemu-system-x86_64 -drive format=raw,file=target/x86_64-blog_os/debug/bootimage-blog_os.bin
```

### 4. 预期结果
您应该看到：
- QEMU 窗口打开
- 显示 "Hello World!" 或类似的输出
- 程序进入无限循环（这是正常的）

## 第五部分：IDE 配置 (5分钟)

### VS Code 配置
1. 安装 VS Code
2. 安装扩展：
   - **rust-analyzer**: Rust 语言支持
   - **CodeLLDB**: 调试支持
   - **Better TOML**: TOML 文件支持

### 3. 创建 VS Code 配置
创建 `.vscode/settings.json`：
```json
{
    "rust-analyzer.cargo.target": "x86_64-blog_os.json",
    "rust-analyzer.checkOnSave.allTargets": false
}
```

```rust
use core::panic::PanicInfo;

#[no_mangle]
pub extern "C" fn _start() -> ! {
    println!("Hello World{}", "!");
    
    loop {}
}

    loop {}
}
```

## 故障排除 🔧

### 常见问题及解决方案

#### 1. Rust 安装失败
```bash
# 如果网络问题，使用国内镜像
export RUSTUP_DIST_SERVER=https://mirrors.tuna.tsinghua.edu.cn/rustup
export RUSTUP_UPDATE_ROOT=https://mirrors.tuna.tsinghua.edu.cn/rustup/rustup
```

#### 2. QEMU 启动失败
```bash
# 检查 QEMU 是否正确安装
which qemu-system-x86_64

# 如果找不到，检查 PATH 环境变量
echo $PATH
```

#### 3. 编译错误
```bash
# 清理并重新编译
cargo clean
cargo build

# 更新工具链
rustup update
```

#### 4. bootimage 安装失败
```bash
# 使用特定版本
cargo install bootimage --version 0.10.3
```

## 今日总结 📝

### 关键概念
1. **裸机编程**: 不依赖操作系统的程序开发
2. **交叉编译**: 为不同目标平台编译代码
3. **引导过程**: 从 BIOS/UEFI 到内核的启动流程
4. **虚拟化**: 使用 QEMU 模拟硬件环境

### 重要文件
- `Cargo.toml`: 项目配置和依赖
- `x86_64-blog_os.json`: 自定义目标规范
- `.cargo/config.toml`: Cargo 构建配置
- `src/main.rs`: 内核入口点
